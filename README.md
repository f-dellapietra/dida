# Istituzioni di Matematica — materiali del corso

Corso di laurea in Scienze per la Natura e per l'Ambiente, a.a. 2026/27 — prof. Francesco Della Pietra.

- [Schede di esercizi (PDF)](esercizi.pdf): una scheda ogni tre lezioni, con le soluzioni in fondo a ciascuna; in coda le schede di recupero.
- [Mappa del corso (PDF)](mappa-del-corso.pdf): il percorso delle 36 lezioni, i blocchi di argomenti e le dimostrazioni da sapere. Si aggiorna dopo ogni lezione.

I file `.tex` sono i sorgenti LaTeX dei due PDF.
